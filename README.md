# AMEZA | Premium Modern E-Commerce Store

A modern, high-conversion e-commerce storefront built with responsive UI, dynamic search & filtering, wishlist persistence, slide-out cart drawer, and interactive product details.

## 🚀 Features
- **Modern Responsive Design**: Optimized for mobile, tablet, and desktop viewports.
- **Hero & Discovery Filter Bar**: Category and price filter directly on the hero banner.
- **Dedicated Wishlist Page**: Fully functional standalone wishlist with `localStorage` persistence and slide-out quick preview.
- **Interactive Cart**: Slide-out cart drawer with live subtotal calculation, coupon discounts, and free shipping progress meter.
- **Clean Sticky Header & Mobile Drawer**: Smooth navigation with category anchors.
- **Quick View Modals**: Fast single-view product details without page refresh.

## 🛠️ Tech Stack
- HTML5 & Vanilla CSS3 (Custom Design System & CSS Variables)
- Vanilla JavaScript (ES6 Modules & LocalStorage State Management)
- Zero build step required — Deploy directly to **Vercel**, **Netlify**, or **GitHub Pages**.
